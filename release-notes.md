# Geurts Performance Prefect 1.22.1

- Added a dedicated **Settings → Repair tools** tab for **Check disk for errors…**, **Fix disk errors…**, **Scan Windows system integrity**, and **Fix Windows image (DISM)…**.
- Kept the existing diagnostic consoles, administrator approval and repair confirmations. Opening the tab does not run any checks or repairs.
- Performance retains Windows aesthetics, Disk Cleanup, Close Boring Applications, power presets and core parking.

Windows x64 and the .NET 10 Desktop Runtime are required. Extract the release ZIP
into your application folder manually, or initiate the update yourself in Settings.
