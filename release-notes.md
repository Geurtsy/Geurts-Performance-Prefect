Adds the emerald suit as the primary Geurts Performance Prefect icon.

- Uses the approved rich emerald design for the executable, taskbar, overlay and Settings window.
- Replaces the generic Windows notification tray icon with the emerald suit.
- Embeds ten Windows icon sizes, from 16 to 256 pixels, for different display scales.
- Includes source PNG exports from 16 to 1024 pixels and the approved master artwork in the repository.

Windows x64 and the .NET 10 Desktop Runtime are required. Extract the release ZIP
into your application folder manually, or initiate the update yourself in Settings.
