Upstream project includes build instructions and dependency acquisition scripts.
The build requires the Windows C++ toolchain and retrieves xxHash when absent.

Both binary and source ZIP are embedded resources in Prefect's assembly, so
previous Prefect updaters can deliver them without expanding their file allowlist.
Settings > Disk analyser > Licence and source extracts the bundled source ZIP
and licence to a temporary folder. No Internet connection is needed.
WinDirStat runs as a separate process with its own temporary portable INI.
No WinDirStat source code is compiled or linked into Prefect.
